# Calcularpromedio

Este es un proyecto para calcular promedios. Puedes acceder a la página del proyecto [aquí](https://petrijomes.github.io/Calcularpromedio/).

## Descripción

Este proyecto está construido usando HTML, CSS, y JavaScript.

## Uso

Para usar este proyecto, simplemente abre el archivo `index.html` en tu navegador web.
